# 诗笺工坊维护

入口：诗歌首页的「诗笺」导航和首页诗笺板块，以及每首诗阅读页的「用这首诗制作诗笺」。

## 访客使用

- **AI 预先精选**：本次由 Codex 阅读并精选的 23 段原诗，点击后随机抽取；不会实时调用模型。
- **随机选段**：从全库或指定的一首诗抽取连续原文。
- **自己选句**：在原文框中选中文字，再点击使用选段；也可以使用整首诗。选段必须是原诗的连续文字。
- **实时 AI**：接通后端后，模型从候选原诗中挑选句段。未配置接口时，页面明确显示「尚未接通」，不会用随机结果冒充 AI。

六种样式支持字号和横竖排选择；包含英文词句的选段使用横排。长诗自动分张。下载 PNG 保存当前一张；打印会包含全部分张，也可以在浏览器打印窗口保存 PDF。分享按钮优先使用设备的分享功能，否则复制可还原当前选段和样式的网址。链接依赖原诗内容保持不变。

## 新诗和新选段

在 `_poems/` 增加诗歌后，卡片全库会随网站构建自动更新，不必单独上传卡片数据。每首诗的 `key` 必须唯一。

要增加 AI 预选句，在 `_data/poetry_cards.yml` 的 `curated` 列表追加：

```yaml
- poem: p-existing-poem-key
  excerpt: |-
    连续原文第一行
    连续原文第二行
```

文字、标点与换行必须与原诗一致。自动检查会拒绝不匹配的选段。可请 Codex 阅读新诗后追加精选；这不会自动触发收费模型接口。

## 接通实时 AI

后端代码和部署步骤在 [server/poetry-ai/README.md](../server/poetry-ai/README.md)。模型凭据只放在后端的 secret 中；前端配置仅填公开服务地址。Codex 当前聊天和订阅不能作为公开网站的访客调用接口。

默认 `realtime_endpoint` 留空。部署后端后，将其 HTTPS 地址写入 `_data/poetry_cards.yml` 即可启用。实时模式需要实际接口验收；仓库测试使用模拟响应，不代表已接通收费模型。
